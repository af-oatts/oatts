# Security Policy
We take security very seriously. OATTS had made numerous decisions in the name of security and privacy, and we intend to keep it that way.
If you discover a security issue with a supported version of OATTS, please use the Reporting A Vulnerability section below. Thank you!
## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x_1.0.xc  | :white_check_mark: |


## Reporting a Vulnerability

To report a vulnerability or security concern please email OATTSContact@dcscorp.com
DO NOT MAKE A PUBLIC ISSUE PLEASE!
