A user can have multiple different flags depending on where they are in terms of OATTS completion. 
That will determine where they are navigated to when logging in and navigating the software.

| Flag | Description |
| --- | --- |
| Onboarded | User gets this flag once they saw the welcome page and selected their interests |
| PreQuizzed | User has completed their allocated pre-quiz(zes) |
| PostQuizzed | User has completed their post quiz |
